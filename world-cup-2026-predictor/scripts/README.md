# Scripts

- `world_cup_predictor_2026.py`: compact teaching version of the tournament simulator.
- `knockout_stage_predictor_2026.py`: predicts known knockout fixtures from `data/knockout_matches.csv`.
- `estimate_dixon_coles_rho.py`: estimates the Dixon-Coles low-score correction parameter.
- `create_third_place_mapping_csv.py`: builds `data/third_place_mapping.csv`.

Note: the main tournament script is a teaching version and uses a simplified seeded knockout. Replace it with your full official-bracket script when you want the exact bracket/third-place mapping workflow.
